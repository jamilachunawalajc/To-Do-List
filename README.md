# To-Do List

A simple To-Do List made using HTML, CSS, and JavaScript. It allows users to add tasks, delete tasks, and manage their daily to-do items.

## Features

* Add new tasks
* Delete tasks
* Mark tasks as completed
* Simple and clean interface
* Tasks are managed dynamically using JavaScript

## Technologies Used

* HTML
* CSS
* JavaScript

## JavaScript Concepts Used

* Functions
* Arrays
* `push()` to add new tasks
* `splice()` to remove tasks
* DOM manipulation
* Event handling
* Loops and conditional statements

## How It Works

The tasks are stored in an array. When a new task is added, `push()` is used to add it to the array. When a task is deleted, `splice()` removes it from the array, and the list is updated on the page using JavaScript.

## Project Purpose

This project was made to practice JavaScript basics, especially working with arrays, functions, DOM manipulation, and user interactions.
